# Setup (5 minutes)

1. The profile repo must be named exactly `AtharvaK-XD/AtharvaK-XD` (public).
2. Copy into its root: `README.md`, the `assets/` folder, and `.github/workflows/profile-3d.yml`.
3. Repo → Actions → "GitHub-Profile-3D-Contrib" → Run workflow (once).
   It creates `profile-3d-contrib/profile-night-green.svg`, then refreshes daily.
4. Until step 3 finishes, the 3D image shows as broken. That is expected.
5. Optional: Profile settings → tick "Include private contributions on my profile".
6. Other 3D styles you can swap into the README: profile-night-rainbow.svg,
   profile-night-view.svg, profile-gitblock.svg, profile-green-animate.svg.
7. After 21 Nov: edit the "LAUNCH" chip in assets/bedrock.svg and the "currently" line.
